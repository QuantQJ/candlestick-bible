# Contributing

## Getting started

```sh
git clone https://github.com/QuantQJ/candlestick-bible.git
cd candlestick-bible
git switch -c your-change
```

Read the README, source provenance, and training-readiness notes. Open an issue to propose a task or submit a focused pull request. Without write access, fork the repository and submit a pull request from your fork. There are no installation steps or training commands yet.

Useful initial contributions include clarifying evaluation criteria, proposing a dataset schema, and improving project documentation. Distinguish proposals from implemented or measured results.

## Working with ChatGPT

If your ChatGPT environment supports a GitHub connection, connect your own account and select this repository through that environment's access controls. Public visibility does not automatically configure access or permit ChatGPT to push changes. Never provide account tokens, passwords, or private checkpoint details in issues, prompts intended for publication, or commits.

## Content boundaries

- Keep the project independent from the existing original trading system.
- Keep any future combined strategy in a separate project.
- Do not commit the PDF, extracted book text, restricted datasets, model weights, credentials, internal paths, or private infrastructure inventories.
- Use original explanations or appropriately licensed material, with provenance.
- Obtain the project owner's agreement before training, paid compute, deployment, or live trading changes.

Public visibility is not a license to redistribute third-party source material or model weights. No project license has been selected yet.
